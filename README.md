# GoShift - Тестовое задание (1С OData + Node.js + Angular)

Веб-приложение для выдачи заказа клиенту: кладовщик открывает заказ из 1С через OData, видит состав заказа и остатки, вводит данные получателя, получает печатный PDF и создаёт в 1С черновик документа реализации.

## Быстрый запуск (Docker Compose)

1. Создайте `.env` на основе `.env.example`:
```
PORT=3000
ONEC_BASE_URL=https://goshift.ru/demo_ut
ONEC_USER=odata.user
ONEC_PASSWORD=Emul-1C-UT-2026
```

2. Запустите:
```bash
docker compose up --build
```

3. Откройте `http://localhost:3000`

## Локальная разработка без Docker

Бэкенд:
```bash
cd server
npm install
npm run dev
```

Фронтенд (dev-сервер с горячей перезагрузкой, порт 4200):
```bash
cd client
npm install
npm start
```

Финальная проверка (как требует задание - сервис сам отдаёт экран с порта 3000):
```bash
cd client && npm run build
cd ../server && npm run dev
```
Откройте `http://localhost:3000`.

## Что показываем как «Остаток»

Физический остаток на складе заказа минус уже отобранное к отгрузке - `ВНаличииBalance - КОтгрузкеBalance` из регистра `ТоварыНаСкладах/Balance`.

Резерв по другим документам (`ТоварыКОтгрузке`) не вычитаем - в демо-данных он оторван от реальности (например, у заказа 00ДМ-000101 зарезервировано больше, чем физически есть на складе), а задание прямо просит показать, «чем склад реально располагает». На заказе 101 это видно: заказано 3 шт. ДМ-0001, в остатке - 2.

## Расчёт сумм и НДС

`server/src/domain/money.ts`, через `decimal.js` (ROUND_HALF_UP):
- сумма строки = количество × цена, округление до копейки
- НДС - от уже округлённой суммы строки, ставка берётся из справочника `Catalog_СтавкиНДС`
- начислять сверху или выделять из суммы решает флаг `ЦенаВключаетНДС` в шапке заказа, не название ставки
- итоги документа - сумма уже округлённых строк

Сверено на реальных данных стенда (заказы 101 и 102) до копейки.

## Склонение ФИО

`server/src/domain/fio.ts`, библиотека `petrovich`. Пол определяется по отчеству. Проверено на несклоняемых фамилиях («Седых», «Коваленко») и обычных.
